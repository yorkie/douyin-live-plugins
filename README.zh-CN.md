# Douyin Live Plugins

[English](README.md)

Douyin Live Plugins 是面向抖音直播伴侣的开源工具与集成项目集合。当前仓库包含 **Lyric Bridge**：一款适用于 macOS 的网易云音乐歌词助手，可同步歌词并通过独立窗口供直播伴侣采集。

## 已包含插件：Lyric Bridge

### 功能

- 识别网易云音乐当前播放歌曲和播放进度。
- 自动搜索带时间戳的歌词及翻译，并同步高亮当前歌词行。
- 支持导入本地 `.lrc` 歌词文件。
- 提供歌词字号、翻译显示、时间偏移和下一首控制。
- 自动打开独立歌词窗，使用紧凑的字幕条布局。

### 环境要求

- macOS 13 或更高版本。
- 从源码构建需要安装 Xcode 命令行工具。
- 识别歌曲和控制播放需要运行网易云音乐。

### 构建与运行

克隆仓库后运行：

```sh
./scripts/build-app.sh
open "build/Lyric Bridge.app"
```

如果登录钥匙串中存在有效的 Apple Development 签名，构建脚本会使用该签名，以便 macOS 在重建后继续将辅助功能授权关联到应用。可以通过 `LYRIC_BRIDGE_SIGNING_IDENTITY` 指定签名身份。若没有可用签名，脚本会使用临时签名；重建后 macOS 可能要求在辅助功能设置中移除并重新添加 Lyric Bridge。

### macOS 权限

Lyric Bridge 需要 **系统设置 → 隐私与安全性 → 辅助功能** 权限，以读取网易云音乐界面中显示的歌曲信息，并在点击“下一首”时向播放器发送切歌操作。请为构建出的 `Lyric Bridge.app` 授权；如果 macOS 提示重新启动应用，请按提示操作。

### 在抖音直播伴侣中使用

1. 启动 Lyric Bridge，歌词条会自动打开。
2. 在抖音直播伴侣中添加“窗口采集”素材。
3. 选择独立窗口 **Lyric Bridge — 歌词**。
4. 根据直播画面调整素材的位置和大小。

歌词条采用紧凑的深色背景。由于 Mac 版窗口采集可能将透明区域合成为不透明黑色，深色底板可以让采集画面呈现为有意设计的字幕条。隐藏 Lyric Bridge 主控制窗口不会关闭歌词条。

### 歌词与网络访问

Lyric Bridge 使用识别到的歌曲名和歌手搜索网易云音乐网页接口，并在可用时获取带时间戳的歌词和翻译。这些接口不是公开的桌面应用 API，未来可能变更或不可用。如果自动匹配失败，可以在控制窗口中选择其他匹配版本，或导入本地 `.lrc` 文件。

应用不需要登录网易云音乐账号，也不会读取账号 Cookie。网络请求使用不保存 Cookie 的临时 URL 会话。

### 常见问题

#### 无法识别当前歌曲

- 打开网易云音乐并开始播放。
- 确认已在 **系统设置 → 隐私与安全性 → 辅助功能** 中允许 Lyric Bridge。
- 修改权限后重新启动 Lyric Bridge。

#### 歌词不匹配或没有歌词

- 在控制窗口中使用“选择匹配版本”选择其他搜索结果。
- 如果没有合适的在线结果，请导入带时间戳的 `.lrc` 文件。
- 检查网络连接；歌词搜索依赖网易云音乐网页接口。

#### 采集列表中没有歌词条

确认歌词条处于打开状态，然后刷新抖音直播伴侣的窗口采集列表，并选择 **Lyric Bridge — 歌词**。
